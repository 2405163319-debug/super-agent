# super-agent

Demo repository for trying dsh-superagent.

## Contents

- `HelloWorld.java` — a minimal Java example.

### Build and run

```bash
javac HelloWorld.java
java HelloWorld
```

Branches named `agent/…` are created by the automation being demoed here; human contributions can follow the same pattern or use any descriptive branch name.

## Contributing

New here? This is a low-pressure demo repository — issues and pull requests of any size are welcome. To get a change merged:

1. **Find or open an issue.** Browse the [open issues](https://github.com/2405163319-debug/super-agent/issues) to see what's being worked on. If you plan to add or change something, open an issue first so others know what you are working on and can discuss the approach.
2. **Create a branch** from the latest `main`:
   ```bash
   git checkout main
   git pull
   git checkout -b feature/short-description
   ```
3. **Make your change.** Keep each pull request small and focused on one thing. Update the README when you add a feature or change how the repository is used.
4. **Commit and push**, then open a pull request against `main`. Describe what changed and why, and link the issue it addresses (for example, `Closes #12`).
5. **Review.** Respond to review comments with follow-up commits. Once the change is approved, a maintainer merges it into `main` and the issue closes automatically.

If anything is unclear, ask in an issue — no question is too small.
