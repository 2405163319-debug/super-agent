# super-agent

Demo repository for trying dsh-superagent.

## Web interface

A small static web interface lives in [`index.html`](index.html). It presents the repository's
programs and lets you run "Hello, World!" from the browser.

To view it, serve the repository root and open the page:

```sh
python3 -m http.server 8000
# then open http://localhost:8000
```

Opening `index.html` directly in a browser also works.
